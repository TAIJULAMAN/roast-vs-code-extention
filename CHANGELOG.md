# Changelog

All notable changes to the "Roast" extension will be documented in this file.

## [0.0.4] - 2026-01-27

### Fixed
- Further optimization of package structure for Marketplace compatibility.
- Standardized extension metadata.

## [0.0.3] - 2026-01-27

### Added
- **New Roast Rules**: 
  - React Anti-patterns: `dangerouslySetInnerHTML`, Index as Key.
  - Security Rules: Hardcoded Secrets, Unsecure HTTP usage.
- **VS Code Diagnostics Integration**: Roasts now appear in the Problems panel.
- **Roast of the Day**: Daily humorous notification on startup.
- **Shareable Statistics**: "Copy for Sharing" feature in stats view.
- **Visual Improvements**: New high-resolution "Angry Fire" extension icon.
- **Metadata**: Added MIT License and standardized package files.

### Fixed
- Fixed icon size issue (optimized from 4.6MB to 30KB).
- Fixed diagnostics scope errors.
- Cleaned up redundant documentation files from the release bundle.

## [0.0.1] - 2026-01-26

### Added
- Initial release of Roast
- Real-time code roasting with decoration API
- 8 core roast rules
